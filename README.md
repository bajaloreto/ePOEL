# ePOEL - Loreto

**Plataforma Digital del Plan de Ordenamiento Ecológico Local de Loreto, Baja California Sur**

## Descripción

ePOEL es una plataforma web interactiva que permite visualizar, explorar y consultar la información del **Plan de Ordenamiento Ecológico Local (POEL)** del municipio de Loreto, B.C.S., México.

La herramienta está diseñada para facilitar el acceso público y técnico a las capas de información territorial, zonificación ecológica, usos de suelo y demás componentes del plan.

## Características principales

- Visualización interactiva de capas geográficas (`capas/`)
- Interfaz moderna y responsive
- Consultas y filtros de información
- Assets optimizados para carga rápida

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- Archivos estáticos (sin backend)

## Cómo usarla

1. Visita la plataforma en:  
   **[https://bajaloreto.github.io/ePOEL](https://bajaloreto.github.io/ePOEL)**

2. Explora las diferentes capas y herramientas disponibles en el visor.
